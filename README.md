# 香港價值觀教育 · 資料站

圍繞《價值觀教育課程架構》（2026）整理的完整資料站。純靜態網頁，零外部依賴，可直接以 GitHub Pages 發佈。

## 內容

- **定位** — 不是獨立科目，而是貫通各學習領域的跨課程框架
- **沿革時間線** — 2008 五個價值觀 → 2021 試行版十個 → 其後增至十二個 → 2026 正式版 → 2026/27 採用
- **總體方向** — 立根中華 · 聯通世界 · 擁抱未來；六個建議加強的重點
- **十二個首要價值觀** — 堅毅、尊重他人、責任感、國民身份認同、承擔精神、誠信、仁愛、守法、同理心、勤勞、團結、孝親
- **跨課程範疇** — 品德倫理、公民、守法、國民、健康生活、生命、性、媒體與資訊素養（含 AI 素養）、可持續發展、法律框架下的人權
- **落實四步** — 檢視現狀 → 訂定重點 → 融入課程 → 檢視成效，附學習期望與全校參與
- **教師支援** — 課程工具、簡介會（CDI020260620）、「同心築夢」推廣運動、與 150 小時 CPD 的接口
- **五個討論議題** — 培育 vs 灌輸、評估困難、教師判斷空間、家校一致性、課程擁擠
- **10 條常見問題**、**4 項限制**、**10 項來源**

## 技術

- `index.html` / `assets/style.css` / `assets/app.js`
- 無框架、無 CDN、無追蹤碼；襯線標題、青瓷綠主色、響應式與列印樣式
- 閱讀進度條、導覽 scroll spy、時間線與價值觀卡片
